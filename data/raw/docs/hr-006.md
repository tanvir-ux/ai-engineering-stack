# Onboarding checklist

During the first week a new employee must complete the security awareness course, set up multi-factor authentication and sign the code of conduct. IT delivers a laptop on the first day. The manager schedules a 30-day, 60-day and 90-day check-in. New employees are assigned a buddy for the first three months. Payroll needs bank details by the Wednesday of the first week to include the employee in the first pay run.
