# Vulnerability management

SECURITY INTERNAL. Critical vulnerabilities must be fixed within 7 days of publication. High severity vulnerabilities must be fixed within 30 days and medium within 90 days. Internet-facing systems are scanned weekly and internal systems monthly. If a fix is not possible in time, the system owner must request a time-limited exception from the security office with a compensating control.
