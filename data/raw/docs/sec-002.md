# Data classification standard

Company data has four classes: public, internal, confidential and restricted. Public data may be shared freely. Internal data is for employees and contractors with a need to know. Confidential data, such as salaries and contracts, is limited to named teams. Restricted data, such as security incident details, needs explicit approval from the security office. Documents must show their class in the header.
